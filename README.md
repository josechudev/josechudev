# Hi, I'm José Chu

**AI Solutions Engineer** at [EPAM](https://www.epam.com) · Guadalajara, Mexico

I help teams take LLM and agent ideas from demo to something that runs in production. I started in **data engineering and MLOps** (Spark on Kubernetes, pipelines, Terraform, model serving), so I care as much about the boring parts, such as evals, observability, cost, deploys and rollbacks, as about the prompt.

## What I'm building

Most of my current work is tooling for **people who work with coding agents**: making agent work visible, reviewable and repeatable.

| Project | What it does |
| --- | --- |
| [**streamlit-a2ui**](https://github.com/josechudev/streamlit-a2ui) | Renders [A2UI](https://a2ui.org) agent-driven UI surfaces inside Streamlit apps, and returns user actions to the agent. Streamlit Components v2, wraps the official web renderer. Release candidate in progress. |
| [**worktrace**](https://github.com/josechudev/worktrace) | Shared workspace memory for coding agents working across several repos on one ticket, served over a local MCP server. |
| [**speckit-lens**](https://github.com/josechudev/speckit-lens) | Extensions for [spec-kit](https://github.com/github/spec-kit): plan readability, execution tracing, spec drift and runtime contract checks. |
| **crewlog** | Local-first ledger of reviewer verdicts for work delegated to AI subagents, with a VS Code view. *(Private for now.)* |

A common thread: agent harnesses (Claude Code, Codex, Copilot), MCP, spec-driven development, and keeping a human sign-off in the loop.
